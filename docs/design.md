# 《雨燕：无尽旋律》（Swift：Endless Melody）游戏策划案

---

## 1. 核心概念与定位 (Executive Summary)

* **游戏类型**：3D 无限飞行 / 节奏收集 / 休闲体验类游戏 (3D Endless Flier / Rhythm Runner)
* **核心意象**：结合“雨燕一生永不落地”的民俗传说，以“飞翔即生存”为核心情感锚点，表达自由、宿命与极致的节奏美感。
* **操控模式**：移动端原生传感器（陀螺仪 + 重力感应），无需虚拟摇杆，带来极具浸入感的体感飞行体验。
* **目标平台**：iOS / Android
* **视觉与调性**：低多边形（Low-Poly）或写意渲染风格，配合空灵清澈的动态音效，呈现“沉浸式极简美学”。

---

## 2. 核心玩法机制 (Core Gameplay Mechanics)

### 2.1 操控与体感 (Controls)

* **姿态控制**：
* **左右倾斜**：控制雨燕横向平移与姿态倾斜（Pitch & Roll）。
* **俯冲与拉升**：向前倾斜设备俯冲加速（增加动能，微幅加快能量消耗）；向后倾斜拉升仰角（降低速度，提高操作精度）。


* **点击交互（辅助）**：
* **单击屏幕**：消耗少许能量执行“羽翼翻滚”（Dodge），用于紧急避险。
* **长按屏幕**：触发“共鸣滑翔”（Glide），进入低能耗模式，降低下坠速度。



### 2.2 能量系统 (Energy System)

* **衰减机制**：
* 能量槽（Flight Stamina）随时间持续自然衰减，衰减速率随飞行距离逐步微幅提升。
* 当能量槽归零时，雨燕失去飞翔动力坠向地面，宣告 **Game Over**（触发“落地”终局演出）。


* **补充机制**：
* **吃音符（Rhythm Notes）**：主要能量来源。音符随背景音乐的节奏在空中呈特定轨迹（如弧线、螺旋线）排列。
* **连击加成（Combo Multiplier）**：连续按音乐节奏吃满一串音符可触发“节奏共振”，回复额外能量并短时间降低能量衰减速度。
* **滑翔翼（Hang Glider）**：穿上滑翔翼后，在低能耗状态下可以自由飞翔，不消耗能量。（有效时长：5秒）



### 2.3 经济与收集系统 (Economic System)

* **金币（Light Feathers / 星芒金币）**：
* 散落在天空各处，位置往往比普通音符更具挑战性（如穿过狭窄的峡谷或气流层）。
* 用于局外养成：解锁不同羽色外观、尾羽轨迹特效、清晨/黄昏/深夜等天空场景主题，以及升级基础能力（如能量上限、金币磁吸范围）。



---

## 3. 动态音乐与关卡设计 (Dynamic Audio & Level Design)

### 3.1 互动音频系统 (Interactive Audio Framework)

* **层叠式音乐（Vertical Layering）**：
* **低能量状态**：背景音乐仅保留单薄的钢琴或弦乐独奏，音效带有沉闷的低通滤波，营造窒息感。
* **高能量/高连击状态**：逐步叠加打击乐、管弦乐或电子合成器，旋律变得丰满激昂。


* **音符采集音效**：
* 每一个被收集的音符不仅是能量补给，更是背景音乐主旋律的构成音符。玩家的飞行轨迹即是在“演奏”这首曲子。



### 3.2 障碍与环境气流 (Environment & Obstacles)

为了防止单调，空中环境分为三种交互要素：

1. **上升气流（Thermal Updrafts）**：视觉呈现为光纤状的风道，进入后无需消耗能量并自动向前加速推进。
2. **逆风与雷暴（Turbulence）**：使陀螺仪控制产生偏移或阻力，考验玩家的体感修正能力。
3. **环境障碍**：如悬崖突石、枯木枝干、高空云层雷电。碰撞会导致大量能量流失并打断连击。

## 4. 情感体验与循环设计 (Game Loop & Emotional Arc)

```
[单局游戏循环]
游戏开始 (空中起飞) ──> 体感飞行 / 避障 ──> 按节奏吃音符 (补充能量) 
       │                                     │
       ▼                                     ▼
  采集金币 (局外资源)                   高 Combo 触发共振 (音乐高潮)
       │                                     │
       └───────────────► 能量耗尽 ◄──────────┘
                           │
                           ▼
                  “落地”终局结算 (展示飞行里程/解锁曲目)
                           │
                           ▼
                  局外升级/外观解锁 ──> 再次起飞

```

### 4.1 终局演出：“一生一次的落地”

当能量耗尽时，游戏不采用生硬的死亡界面，而是转入慢动作镜头：

* 雨燕从高空缓缓滑翔盘旋，俯瞰过往飞过的壮丽山川。
* 伴随着一曲温柔舒缓的离别残音，雨燕触碰地面的瞬间化为无数光芒羽毛散去，结算界面弹出：**“你已飞过 [X] 公里，演奏了 [Y] 秒的乐章”**。
* 强化“落地即是终章，但飞过的轨迹永存”的情感体验。

## 5. 商业化与系统拓展规划 (Monetization & Expansion)

1. **外观与个性化（无数值纯外观）**：
* **雨燕皮肤**：玄青雨燕、极光雨燕、机械高光雨燕等。
* **粒子拖尾**：星尘轨迹、乐谱光带、水墨风烟等。


2. **曲目关卡扩展**：
* 采用“天空章节”模式，每个章节对应一种特定的音乐风格（如 Chillhop 宁静高山、Symphonic 壮丽云层、Synthwave 霓虹夜空）。


3. **广告与内购**：
* 非强制性激励视频（例如：落地后观看广告获取“风之庇护”复活一次，或结算金币翻倍）。
